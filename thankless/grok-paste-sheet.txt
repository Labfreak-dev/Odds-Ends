HOW TO USE (in Grok chat / Grok Imagine):
1. Copy ONE block below and paste it to Grok with this line in front:
   "Generate one square image for each numbered prompt below, one at a time."
2. Download the images it gives you.
3. EITHER save each one under the filename shown for its number, into
   thankless/art-src/ (png, jpg or webp all work), then run
       python3 thankless/pack-art.py
   and reload the game — OR drag them into the repo chat and say which block
   they came from; Claude names, keys, packs and ships them.
Missing images keep their vector stand-ins, so stop whenever you like: every
block that ships goes live on its own. No API key needed for this route.

RULES THAT MATTER
- Sprites and props must come back on a flat MAGENTA background: the packer
  keys on it. Wrong background, or pink anywhere in the character, ask again.
  Faces, tiles and the title keep their backgrounds.
- Everything faces RIGHT. The game flips it when needed.
- One style for the whole set. Do block 1 (the party idles) first; if the look
  is right, keep going. If not, change the style words and redo block 1.
