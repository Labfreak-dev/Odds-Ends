# Loot & Daggers art sheet — one line per image: filename | prompt
#
# The name before the dot is the sprite key the game looks up in window.LD_ART
# (art.js). Keep it exact. Anything missing keeps its built-in vector fallback,
# so art can ship in waves.
#
# Kinds by prefix:
#   bg_     side-view background strip, seamless LEFT-TO-RIGHT, background kept
#   title   menu painting, 16:9 crop, background kept
#   sym_    slot-machine reel symbol, keyed off magenta, square, fitted to 128px
#   (else)  character / enemy / prop sprite, keyed off magenta, trimmed, fitted to 128px
#
# Sprites are keyed on MAGENTA. Every sprite prompt ends with the magenta lock,
# and nothing in a design may be magenta or hot pink.
# Characters and enemies face RIGHT: the game mirrors enemies so they face the hero.
#
