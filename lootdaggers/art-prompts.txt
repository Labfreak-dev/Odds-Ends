# Loot & Daggers art sheet — one line per image: filename | prompt
#
# The name before the dot is the sprite key the game looks up in window.LD_ART
# (art.js). Keep it exact. Anything missing keeps its built-in fallback, so
# art can ship in waves.
#
# LOOK: gothic horror in the vein of Darkest Dungeon — hand-inked comic art,
# thick jagged black ink, big slabs of black shadow, stark torchlight,
# desaturated bone/rust/ash palette with dried-blood crimson and sickly green
# accents. Characters gaunt and haggard; everything worn, rotten, oppressive.
# (The prompts describe the look rather than naming the game, which keeps
# them working across image generators.)
#
# Kinds by prefix:
#   bg_     side-view background strip, seamless LEFT-TO-RIGHT, background kept
#   title   menu painting, 16:9, background kept
#   sym_    slot-machine reel symbol, keyed off magenta, square, fitted to 128px
#   portrait_, screen_   background kept
#   relic_ gear_ slot_ altar_ mod_ intent_ ui_ shop_ fx_   keyed off magenta, square icons
#   (else)  character / enemy / prop sprite, keyed off magenta, trimmed, fitted to 128px
#
# Sprites are keyed on MAGENTA. Nothing in a design may be magenta or hot pink.
# Characters and enemies face RIGHT: the game mirrors enemies to face the hero.
#
#
# STATUS: the game ALREADY READS every key above the first "NEW ·" section
# (heroes, enemies, bosses, props, reel symbols, bg_wall, bg_floor, title).
# Everything in a "NEW ·" section replaces an emoji or placeholder that is
# still in the game; those get wired up in code when the art arrives.
#
# ---- style locks (copied into every line so each prompt is self-contained) ----
