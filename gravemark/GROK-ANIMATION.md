# Gravemark — animation request

_Generated by `tools/grok-animation.js` from a live scan of `art/`. Regenerate after every delivery._

**112 animations are currently a single still frame.** They load, they play, and nothing moves.

## Read this first — it is the whole reason eight packs produced no animation

Every previous delivery asked for *"an 8-frame sprite sheet"* and returned **the same pose copied eight times**. That is not a quality problem, it is a format problem: an image generator makes one picture per prompt and cannot lay out a strip.

So do not ask for a sheet. **Ask for one pose at a time, numbered.**

The game reads frame count from each image's own width, so a **3-frame animation is completely valid art**. Three real key poses beat eight identical ones. Deliver separate files:

```
actor/hero-attack-sword-1.png      wind-up
actor/hero-attack-sword-2.png      the strike
actor/hero-attack-sword-3.png      recovery
```

They get stitched into the strip the game wants with one command, which also keys out the background:

```bash
python3 tools/make-sheet.py <folder>
```

### The rule that makes or breaks every one of these

> **Every frame of an action must be the same character, at the same size, at the same distance, with its feet in the same place. ONLY the pose changes.**

When prompting frame 2, **attach frame 1 as a reference image** and say:

```
Identical character, identical art style, identical camera distance and scale,
feet in exactly the same place in frame. Change ONLY the pose, to: <beat>.
```

Without that they come back as three different drawings of a similar character and the animation strobes instead of moving. This is the single most important instruction in this document.

## The style block — paste this above every prompt

```
Hand-painted 2D game sprite for "Gravemark", a Lovecraftian gravedigging action-RPG.

STYLE: painterly hand-painted 2D with visible brush texture. Cold, damp, cut stone.
NOT vector, NOT pixel art, NOT 3D render, NOT cartoon, NOT anime.

LIGHT: one low warm key source against cold blue-grey ambient fill, rim light to
separate the figure from the ground.

VALUE: dark overall. Narrow bright range kept for bone, metal and lamplight.
The silhouette must read clearly at 25% scale.

COLOUR: desaturated blue-grey base (#0c0d10 to #3d4454), exactly ONE saturated accent.
Bone #e6e0cf is the brightest neutral.

FRAMING: full body, the whole figure inside the frame, feet near the bottom edge,
nothing cropped. Square image.

BACKGROUND: flat solid magenta #FF00FF, edge to edge. No gradient, no shadow cast
onto it, no vignette, no border, no ground line.

NO text, letters, numbers, watermark, signature or logo anywhere in the image.
```
