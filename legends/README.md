# Labfreak Legends

A Hearthstone-style card battler built from every Labfreak game: Glimmerdeep, Dead Man's Pull,
Thankless, Odds & Ends, Ironhold Idle, and the Labfreak Series 1–3 and Multiverse card packs.

Cards come in sets, Hearthstone-style. The Core Set (2,318 cards) is the original game; each expansion
adds its own pack, a set symbol on its cards and a new keyword:

| Set | Cards | Built from | Brings |
|---|---|---|---|
| Core Set | 2,318 | Glimmerdeep, Dead Man's Pull, Thankless, Odds & Ends, Labfreak series | the five original classes |
| Siege of Ironhold (`ih`) | 190 | Ironhold Idle's art (`ironhold/art.js`, its item icons) | the Champion class; **Frenzy** (acts the first time it survives damage) |
| The Deep Catch (`dc`) | 152 | the Odds & Ends fishing art (`workshop/fishing-*.module.js`) | **Dredge** (look at the bottom 3 cards of your deck, put one on top) |
| Tricks of the Trade (`tt`) | 74 | Ironhold Idle's trinket icons and the Odds & Ends curios | synergy spells and weapons for every class |
| Rise of the Pantheon (`pt`) | 73 | the Odds & Ends gods-and-heroes portraits (`art/`) and a few curios | **Choose One**, **Echo**, **Magnetic**, **Tradeable**, **Quests**, **Hero cards**, **Start of Game** |

Many minions in every set carry synergy abilities (tribe lords, "for each", "if you control", cost cuts, deck tutors). The rules for which cards get them live in `synergize()` in `tools_gen_cards.py`.

No build step. Open `index.html` from any static host (GitHub Pages works; drop this folder in as
`/legends/`). Opening the file straight from disk won't work in most browsers because of
the scripts, so use a local server: `python3 -m http.server`, then visit http://localhost:8000.

| Path | What it is |
|---|---|
| `index.html` | Page shell and all CSS |
| `js/engine.js` | Rules engine, pure logic with no DOM. Runs in Node for headless bot-vs-bot games. `botStep` is the fast greedy bot (used by the generators), `botStepSmart` the lookahead bot the game plays against |
| `js/ui.js` | Menus, collection and deck builder, battle board, campaign and cutscenes, animation, sound |
| `js/voice.js` | Emote and voice lines for each class, and how bots answer (data only) |
| `data/recipes.js` | GENERATED by `tools_gen_recipes.js`: the twelve pre-made decks (two per class) |
| `data/meta.js` | GENERATED by `tools_gen_meta.js`: each card's win rate in random bot games; Ranked and Arena bots build stronger decks from it |
| `js/campaign.js` | The campaign: six class stories and a finale, every line of dialogue, bosses and rewards (data only) |
| `data/cards.js` | GENERATED: 2,807 cards in five sets, tokens, heroes, atlas index (`window.LL_DATA`) |
| `img/a00–a36.webp` | GENERATED: Core Set art atlases, 8×8 cells of 192 px |
| `img/a37–a42.webp` | GENERATED: expansion art atlases |
| `img/fx.webp`, `img/bg_*.webp` | Spell effects and battle boards |
| `img/ui/` | The painted UI kit: nine-slice frames, buttons, tabs and ribbon copied from `thankless/ui` (`ui_*.webp`), twelve menu icons (`ic_*.webp`), and the six element rings from `glimmerdeep/img/frames` worn by minions on the board (`ring_1..6.webp`) |
| `sfx/` | Copied from `glimmerdeep/sfx`, `glimmerdeep/sfx2` (element casts and hits), `glimmerdeep/music`, `iron-league/assets/audio/sfx` (spell casts and impacts by class, weapon hits) and `thankless/sfx` |
| `tools_gen_cards.py` | The Core Set generator (writes `data/cards.js` and `img/a00–a36`) |
| `tools_gen_sets.py` | The expansion generator: run it after `tools_gen_cards.py`; it appends both expansions to `data/cards.js` and writes `img/a37+`, reading every asset straight from the repo |
| `tools_gen_recipes.js` | Pre-made decks: each recipe names its key cards, what fits and what pays off; the rest is filled by card power on a mana curve, then every recipe is tested in bot games. Run after `tools_gen_meta.js` |
| `tools_gen_meta.js` | Card power for bot decks: `node legends/tools_gen_meta.js` after regenerating cards (60,000 games, about a minute) |
| `tools_gen_packs.py` | Pack foils, reveal sigils, card backs and pack sounds for the Card Shop |

Progress saves in the player's browser (localStorage): decks `ll_decks`, owned cards `ll_owned`, golden copies `ll_golden`, gold `ll_gold`, reagents `ll_dust` (the crafting currency; the key kept its old name so saves carry over), campaign progress `ll_camp`, daily quests `ll_quests`, reward-track level `ll_prog`, packs waiting to be opened `ll_free` (bought or earned), cosmetics `ll_cos` (card back, hero portraits), win counts `ll_stats`, Ranked `ll_rank`, Arena run `ll_arena` and best `ll_arena_best`, Brawl prize `ll_brawl`, turn timer `ll_timer`, Play tab `ll_pmode`, plus `ll_chosen`, `ll_sound`, `ll_tips`, `ll_read`, `ll_jseen`.

Economy, in `js/ui.js`: crafting and disenchant costs (`CRAFT`, `DE`, `CRAFT_G`, `DE_G`), golden odds (`GOLD_ODDS`), quests (`QDEF`), the reward track (`trackReward`, `xpNeed`), card backs (`BACKS`, art from Rip & Ship, written to `img/back_*.webp` by `tools_gen_packs.py`) and hero portraits (`PORTS`). Deck codes are `LL1.<class>.<singles>.<doubles>`, five base-36 characters per card (an FNV hash of its id).

Packs and prices live in the `PACKS` list in `js/ui.js`; battle rewards are in `gameOver()`.

Modes, in `js/ui.js` under MODES: Ranked (`rankEnd`, `rankK` sets how strong the bot's deck is per league), Arena (`arenaOffer`, `ARENA_GOLD`), Tavern Brawl (`BRAWLS`, one per week counted from Monday 5 January 2026; rule hooks are `opts.mods` in the engine: `manaStart`, `cost`). The turn timer is `TURN_MS` (tests can shorten it with `window.LL_TURN_MS`).

Card fields for the Pantheon mechanics (all read by `js/engine.js`): `ch` = Choose One options `[{n, fx}]` (the hand card's `ci.choice` picks one, `cardOf()` folds it in); `kw` `echo`, `magnetic` (the hand card's `ci.mag` names the Mech to fuse into), `tradeable` (`trade()`); `q` = quest `{k: play|cast|kill|face, n, f, rw}` with the reward card in `rw`; `t: "h"` = hero card (`h` is its Armor, `hp` its Hero Power); trigger `sog` = Start of Game, with the condition `if: {nodup: true}` for "if your deck has no duplicates".

The look: every button is a painted nine-slice plate (`.big` brass, `.big.alt` iron, `.big.camp` the red banner, `.small` the iron tab, `.small.gold` the brass tab); screen titles sit on the parchment ribbon; dialogs wear the oak frame; tiles (decks, packs, quests, chapters, recipes) wear the iron tab. The main menu is a hub with a HUD (level, XP, gold, reagents, sound) and icon buttons, and every other screen has a bottom tab bar (Home, Play, Shop, Cards, Quests). On the board each minion wears a ring by element or tribe (`RING` in `js/ui.js`: vine, ice, lava, amethyst, cloud) and Legendaries, hero cards and heroes wear the gold ring.
