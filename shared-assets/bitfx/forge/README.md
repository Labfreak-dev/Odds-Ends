# BitFX Forge

Windows desktop tool shipped beside the premade FX packs in
[`../packs/`](../packs/). Those spritesheets are the part this repo keeps.

`BitFX Forge.exe` (about 10 MB in the archive) is not committed. The
Character-asset-gen v1 release does not include it either, so treat the
executable as a local tool. A PyInstaller blob under `source/` in the same
archive was left out with it.
